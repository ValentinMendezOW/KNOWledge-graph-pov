# Unleashing Developer Productivity with Generative AI

**Source:** McKinsey & Company — McKinsey Digital
**Date:** June 27, 2023
**URL:** https://www.mckinsey.com/capabilities/mckinsey-digital/our-insights/unleashing-developer-productivity-with-generative-ai

---

## Overview

McKinsey conducted an empirical study to measure how generative AI tools affect software developer productivity. The study found that developers can complete coding tasks **up to twice as fast** when using generative AI, though results vary significantly by task complexity and developer experience level. The research also revealed substantial improvements in developer well-being and job satisfaction.

## Study Methodology

- **Participants:** More than **40 McKinsey developers** located across the United States and Asia
- **Experience levels:** Developers with varying amounts of software development experience
- **Duration:** Several weeks of controlled testing
- **Task areas:** Code generation, code refactoring, and code documentation
- **Design:** Each task was performed by a test group with access to **two generative AI-based tools** and a control group with no AI assistance. Each developer participated in both groups (test group for half the tasks, control group for the other half).

## Key Findings: Speed Improvements by Task Type

### Code Documentation
- **45-50% reduction** in time to complete
- Documenting code functionality could be completed in roughly **half the time**

### Code Generation
- **35-45% reduction** in time to complete
- Writing new code could be done in **nearly half the time**

### Code Refactoring
- **20-30% reduction** in time to complete
- Optimizing existing code could be done in **nearly two-thirds the time**

### High-Complexity Tasks
- **Less than 10% reduction** in task completion time
- Generative AI increases developer speed but is notably **less effective for complex tasks**

## Variation by Developer Experience

A critical and nuanced finding emerged around developer skill levels:

- **Highly skilled developers** saw productivity gains of **50 to 80 percent**
- **Junior developers** experienced a **7 to 10 percent decline** in speed
- This suggests that generative AI tools amplify existing expertise rather than replacing foundational skills
- Less-experienced developers may struggle to effectively evaluate and integrate AI-generated suggestions

### Detailed Impact by Experience Level

**Junior Developers (0-2 years)**
- Salary range: $55,000-$80,000 annually
- Team composition: 10-20%
- AI benefits: Guidance on syntax errors, code suggestions, test automation
- Projected Year 1 productivity gain: ~14% (but initial speed impact was negative in the study)

**Mid-Level Developers (2-5 years)**
- Salary range: $80,000-$120,000 annually
- Team composition: 50-60% (largest group)
- AI benefits: Optimization suggestions, routine task automation, early bug detection

**Senior Developers (5-10+ years)**
- Salary range: $120,000-$175,000 annually
- Team composition: 15-25%
- AI benefits: Issue identification, code improvement suggestions, security vulnerability detection

**Technical Leads/Architects (10+ years)**
- Salary range: $175,000-$250,000 annually
- Team composition: 5-10%
- AI benefits: Architectural issue identification, design pattern recommendations, automated code review

## Developer Experience and Well-Being

Equipping developers with generative AI tools significantly improved their experience:

- Developers using AI tools were **more than twice as likely** to report:
  - Overall **happiness**
  - **Fulfillment** in their work
  - A state of **flow**
- Improvements were attributed to:
  - Automation of tedious, routine work
  - Faster information access compared to traditional search methods
  - Reduced time on boilerplate and repetitive coding tasks
  - More time available for creative and high-value work

## Broader Context: GitHub Copilot Data

Supporting McKinsey's findings, external data showed:
- **GitHub Copilot** users completed coding tasks **56% faster** than non-users
- Fortune 500 companies reported over **100 million active weekly ChatGPT users** as of November 2023

## Projected Five-Year Business Value

Over a five-year transformation timeline, the following improvements were projected:

- **15-20% increase** in the number of new products or features developed
- **10-15% reduction** in bugs found in production
- **5-10% increase** in customer retention and loyalty
- **10-15% reduction** in time-to-market for new products or features
- An average **60% productivity improvement** across all developer roles over five years

## Strategic Recommendations

Maximizing productivity gains and minimizing risks when deploying generative AI-based tools requires engineering leaders to take a structured approach:

1. **Training and coaching** — Invest in comprehensive generative AI training programs for developers at all levels
2. **Use case selection** — Start with well-defined use cases where AI tools have demonstrated clear value (e.g., documentation, boilerplate code generation)
3. **Workforce upskilling** — Ensure developers build foundational skills alongside AI tool proficiency
4. **Risk controls** — Implement code review processes and quality gates for AI-generated code
5. **Pricing model evolution** — Consider shifting from labor-based to value-based or performance-based pricing models to align incentives with productivity gains

## Key Takeaway

Generative AI has significant potential to accelerate software development, but organizations must pair tool deployment with deliberate training, quality assurance, and change management strategies. The technology works best as a force multiplier for skilled developers rather than as a replacement for foundational engineering expertise.
